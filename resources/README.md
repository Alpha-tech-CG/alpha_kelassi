# Alpha Kelassi — Ressources Média & Maquettes Design

Ce dossier héberge les éléments graphiques, médias pédagogiques et archives de prototypes design pour l'application **Alpha Kelassi**.

## Structure du Dossier

```
resources/
└── assets/
    ├── images/            # Illustrations, schémas anatomiques & médias de cours
    └── design_archives/   # Archives ZIP des exports et maquettes UI (Stitch / Design final)
```

## Contenu des Médias (`images/`)

- Schémas explicatifs : Appareil digestif, appareil respiratoire, circulation sanguine, structure osseuse, oeil.
- Utilisés pour l'enrichissement des cours et fiches interactives.

## Archives de Design (`design_archives/`)

- Maquettes de référence UI/UX (exportations Stitch & Design final).
