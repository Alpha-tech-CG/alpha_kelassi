### L'axe de symétrie

Une figure a un **axe de symétrie** quand, en la pliant le long d'une droite, les deux parties se **superposent exactement**. Cette droite est l'**axe**.

| Figure | Nombre d'axes de symétrie |
|---|---|
| Le **carré** | 4 |
| Le **rectangle** | 2 |
| Le **cercle** | une infinité (tous les diamètres) |
| Le **triangle équilatéral** | 3 |
| Le **triangle quelconque** | aucun |

Autour de nous : un papillon, un visage, une feuille d'arbre, le drapeau plié en deux.

### Tracer le symétrique d'un point

1. Depuis le point, je trace une ligne **perpendiculaire** à l'axe.
2. Je mesure la distance entre le point et l'axe.
3. De l'autre côté, je reporte **la même distance** sur cette ligne.
4. Je marque le nouveau point : c'est le **symétrique**.

Le symétrique d'une figure se construit point par point, puis on relie les points obtenus. La figure obtenue a la **même taille** et la **même forme** : seul le sens change, comme dans un miroir.

### Se repérer sur un quadrillage

Sur un quadrillage, chaque case se repère par une **colonne** (une lettre) et une **ligne** (un chiffre) : la case **B3** se trouve dans la colonne B, à la ligne 3. On lit toujours la **colonne d'abord**, puis la **ligne**.

Pour reproduire une figure sur quadrillage, on compte les **carreaux** : « 3 carreaux à droite, 2 carreaux vers le haut ».

### ⚠️ Piège à éviter

Le symétrique n'est pas une figure **décalée** : chaque point doit être à la **même distance** de l'axe, de l'autre côté.

### ✏️ À toi de jouer

1. Combien d'axes de symétrie a un carré ? un rectangle ?
2. Un point est à 3 carreaux à gauche de l'axe. Où se trouve son symétrique ?
3. Comment lit-on la case D5 ?

### ✅ Réponses

1. Le carré en a 4, le rectangle en a 2. 2. À 3 carreaux à droite de l'axe, sur la même ligne. 3. Colonne D, ligne 5.
