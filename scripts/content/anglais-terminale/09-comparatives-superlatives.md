Le **comparatif** compare deux éléments ; le **superlatif** désigne l'extrême d'un ensemble (le plus / le moins). La forme dépend de la **longueur de l'adjectif**.

> **📘 Règle de base**
> Adjectif **court** (1 syllabe) → **-er / -est**. Adjectif **long** (2 syllabes et +) → **more / most**.

## 1. Le comparatif de supériorité (« plus … que »)

| Type d'adjectif | Forme | Exemple |
|---|---|---|
| court | adj + **-er** + than | Tom is **taller than** Sam. |
| long | **more** + adj + than | This book is **more interesting than** that one. |

## 2. Comparatif d'égalité et d'infériorité

- Égalité (« aussi … que ») : **as** + adjectif + **as** → *She is **as tall as** her brother.*
- Infériorité (« moins … que ») : **less** + adjectif + **than** → *This is **less difficult than** that.*

## 3. Le superlatif (« le plus / le moins »)

| Type | Forme | Exemple |
|---|---|---|
| court | **the** + adj + **-est** | He is **the tallest** in the class. |
| long | **the most** + adj | It is **the most beautiful** city. |

## 4. Orthographe des adjectifs courts

- consonne + y → **-ier / -iest** : *happy → happier → the happiest.*
- voyelle + consonne → on double : *big → bigger → the biggest.*

## 5. Les irréguliers (à connaître)

| Adjectif | Comparatif | Superlatif |
|---|---|---|
| good | better | the best |
| bad | worse | the worst |
| far | farther / further | the farthest / furthest |
| little | less | the least |
| much / many | more | the most |
