Ce chapitre réunit trois règles de base sur le **nom** : les **articles** (a / an / the), le **pluriel**, et les **quantifieurs** (some, any, much, many…).

## 1. Les articles

| Article | Emploi | Exemple |
|---|---|---|
| **a** | devant un son **consonne**, chose indéfinie | **a** book, **a** university (son « you ») |
| **an** | devant un son **voyelle** | **an** apple, **an** hour (h muet) |
| **the** | chose définie, déjà connue | **the** sun, **the** book I bought |
| **Ø** (rien) | généralités, noms indénombrables au sens général | I like Ø music. Ø Dogs are loyal. |

## 2. Le pluriel des noms

| Règle | Singulier → Pluriel |
|---|---|
| général : + **-s** | car → car**s** |
| en -s, -ss, -sh, -ch, -x : + **-es** | box → box**es**, watch → watch**es** |
| consonne + y → **-ies** | city → cit**ies** |
| en -f / -fe → **-ves** | leaf → lea**ves**, knife → kni**ves** |

**Pluriels irréguliers :** man → men, woman → women, child → children, foot → feet, tooth → teeth, person → people, mouse → mice.

## 3. Dénombrables et indénombrables

- **Dénombrables** : se comptent (one book, two books).
- **Indénombrables** : ne se comptent pas (water, money, information, advice, bread). Pas de pluriel, pas de *a/an*.

## 4. Les quantifieurs

| Quantifieur | Emploi | Exemple |
|---|---|---|
| **some** | quantité indéfinie (affirmatif) | I have **some** money. |
| **any** | négatif et interrogatif | I don't have **any** money. Have you **any**? |
| **much** | indénombrable (nég./quest.) | How **much** water? |
| **many** | dénombrable pluriel | How **many** books? |
| **a lot of / lots of** | beaucoup (affirmatif) | I have **a lot of** friends. |
| **a few** | quelques (dénombrable) | **a few** apples |
| **a little** | un peu (indénombrable) | **a little** sugar |

**Exemples :**
- There are **many** students but there isn't **much** space.
- Would you like **some** tea? — No, I don't want **any**, thank you.
