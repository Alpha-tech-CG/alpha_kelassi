L'orthographe permet d'écrire correctement ; le vocabulaire permet de comprendre et de s'exprimer avec précision. Ce chapitre révise les accords, les homophones, l'enrichissement du vocabulaire et la formation des mots.

### I. Les accords

#### 1. L'accord sujet-verbe

Le verbe s'accorde en **personne** et en **nombre** avec son sujet.

- *Les élèves **travaillent**.* (sujet pluriel → verbe pluriel)
- *Le chien et le chat **dorment**.* (deux sujets → pluriel)

> **Attention** — Quand le sujet est éloigné ou inversé, cherche-le en posant la question *« qui est-ce qui + verbe ? »*.
> *Dans la cour **jouent** des enfants.* → qui est-ce qui joue ? *des enfants* → pluriel.

#### 2. L'accord de l'adjectif

L'adjectif qualificatif s'accorde en **genre** et en **nombre** avec le nom qu'il qualifie.

- *une **grande** maison*, *des murs **blancs***.

#### 3. L'accord du participe passé

- Avec **être** : il s'accorde avec le **sujet**.
  - *Elles **sont arrivées** tôt.*
- Avec **avoir** : il s'accorde avec le **COD** seulement si celui-ci est placé **avant** le verbe.
  - *J'ai mangé **les mangues**.* → COD après → pas d'accord.
  - *Les mangues **que** j'ai mang**ées**.* → COD (*que = les mangues*) avant → accord.
- Sans auxiliaire (employé comme adjectif) : il s'accorde avec le nom.
  - *des fruits **mûrs***.

### II. Les homophones grammaticaux

Ce sont des mots qui se **prononcent de la même façon** mais s'écrivent différemment. On les distingue par leur **nature** ou par un **remplacement**.

- **a / à** : *a* = verbe avoir (remplaçable par *avait*) ; *à* = préposition. → *Il **a** faim ; il va **à** l'école.*
- **est / et** : *est* = verbe être (*était*) ; *et* = conjonction (*et puis*). → *Il **est** grand **et** fort.*
- **son / sont** : *son* = possessif (*mon*) ; *sont* = verbe être (*étaient*). → *Ils **sont** dans **son** jardin.*
- **ce / se** : *ce* = déterminant/pronom démonstratif ; *se* = pronom réfléchi (devant un verbe). → *Ce livre **se** lit vite.*
- **ces / ses** : *ces* = démonstratif pluriel (*ceux-là*) ; *ses* = possessif (*les siens*). → *Il range **ses** affaires dans **ces** boîtes.*
- **ou / où** : *ou* = « ou bien » ; *où* = lieu. → *La ville **où** tu vis, grande **ou** petite ?*
- **on / ont** : *on* = pronom (*il*) ; *ont* = verbe avoir (*avaient*). → *On dit qu'ils **ont** gagné.*

### III. L'enrichissement du vocabulaire

- **Le champ lexical** : ensemble des mots qui se rapportent à un même thème. *Champ lexical de la mer : vague, marée, port, bateau, sel…*
- **Les synonymes** : mots de sens proche. *content = heureux = joyeux.*
- **Les antonymes** (contraires) : *grand ≠ petit*, *monter ≠ descendre*.
- **Les homonymes** : même son, sens différents. *un ver, un verre, vers, vert.*
- **Le sens propre et le sens figuré** : *une pierre dure* (propre) / *un cœur dur* (figuré).

### IV. La formation des mots

Beaucoup de mots sont construits à partir d'un **radical** (la partie porteuse du sens) auquel on ajoute des affixes.

- **Le préfixe** se place **avant** le radical et change le sens.
  - *re-* (répétition) : *refaire* ; *in-/im-* (contraire) : *impossible* ; *dé-* : *défaire*.
- **Le suffixe** se place **après** le radical et change souvent la nature du mot.
  - *-tion* (nom) : *punir → punition* ; *-able* (adjectif) : *aimer → aimable* ; *-ment* (adverbe) : *lent → lentement*.
- **La famille de mots** : mots formés sur un même radical. *terre → terrain, terrestre, enterrer, souterrain.*

### À retenir

- Le verbe s'accorde avec son **sujet** ; l'adjectif avec son **nom** ; le participe passé avec **être → sujet**, avec **avoir → COD placé avant**.
- Les **homophones** se distinguent par un remplacement (*a/avait*, *est/était*, *sont/étaient*, *ont/avaient*).
- Enrichir son vocabulaire : champs lexicaux, synonymes, antonymes, sens propre / figuré.
- Les mots se forment avec un **radical** + **préfixe** (devant) et **suffixe** (derrière).
